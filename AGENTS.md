# CareFlow AI Prototype

## Project
Static React prototype for an AI-assisted healthcare clinic workflow platform. Hosted on GitHub Pages. No backend, no real auth, no real AI — all data is mocked.

## Tech Stack
- Bun (package manager)
- Vite + React + TypeScript
- Tailwind CSS v4 (via `@tailwindcss/vite` plugin)
- `react-router-dom` with `HashRouter`
- `lucide-react` for icons

## Commands
- `bun install` — install dependencies
- `bun run dev` — start dev server
- `bun run build` — production build to `dist/`
- `bun run lint` — run eslint

## Structure
- `src/app/` — router config
- `src/components/layout/` — Shell, Navbar
- `src/data/` — mock data (patients, prescriptions, reports, AI suggestions, consultations, dashboard)
- `src/pages/` — 10 page components (Landing, Overview, Roles, Doctor, Compounder, Patient, Consultation, History, AiInsights, Workflow)
- `src/types/` — TypeScript interfaces
- `src/utils/` — formatting helpers
- `src/styles/globals.css` — Tailwind entry with custom theme tokens

## Conventions
- HashRouter only (GitHub Pages compatibility)
- All data is static imports from `src/data/` — no state management libraries
- Role colors: Doctor=teal, Compounder=amber, Patient=green
- All AI outputs must include a disclaimer banner
- Flagship demo patient: Ananya Sharma (P001) — used across all screens for continuity

## Git
- Never add "Generated by" or "Co-Authored-By" lines in commits or PR descriptions.

## Deploy
GitHub Pages via `.github/workflows/deploy.yml`. Pushes to `main` auto-deploy.
